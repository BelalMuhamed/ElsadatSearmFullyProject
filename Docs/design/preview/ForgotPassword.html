نسيت كلمة المرور؟

اكتب اسم المستخدم أو الموبايل، والطلب هيوصل لمسؤول النظام يعملك كلمة مرور مؤقتة.

اتبعت. لو الحساب موجود، هيتواصل معاك مسؤول النظام بكلمة مرور مؤقتة. أول ما تدخل بيها هيطلب منك تغيّرها.

الرسالة دي واحدة سواء الحساب موجود أو لأ — عشان محدش يقدر يجرّب أرقام ويعرف مين عنده حساب.
