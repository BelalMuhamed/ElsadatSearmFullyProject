## Items

### C1 — Role names accepted from the client (privilege escalation)
- `Infrastructure/Services/EmployeeServices/EmployeeService.cs` ~L78–86 (`AddToRolesAsync(user, DTo.RolesName)` on create) and ~L478–496 (on update).
- `Infrastructure/Services/RepresentativeServices/RepresentativeService.cs` ~L71–79 and ~L225–231 (`AddToRoleAsync(user, DTo.RoleName)`).
- `Application/DTOs/EmployeeDtos/EmployeeDTo.cs` L40 `RolesName`.
- Impact: anyone with employee-create permission can create an Admin → `super_admin` bypass.
- Direction: the server decides the role from the user type (Employee / Representative); stop reading role names from input DTOs. Roles become permission categories in M1, so don't build anything new on roles — just remove the client control. Keep read-only role output only if a current screen needs it (ask Belal).

### C2 — Hardcoded customer password
- `Infrastructure/Services/DistributorsAndMerchantsService.cs` L91: `HashPassword(user, "12345678Ss+")`.
- Plan's direction: create the customer without a usable password; the admin activates the login later with a temporary password that must be changed on first login. Present options and wait for Belal's choice.

### C3 — Customer edit accepts balances from the frontend
- `EditDistributorOrMerchant` (service + `AlSadat-Seram.Api/Controllers/DistAndMerchController.cs`): `PointsBalance`, `CashBalance`, `Indebtedness` are writable.
- Direction: remove those fields from the edit DTO/mapping; balances change only through documents (invoices, vouchers, points transactions).

### C15 — `publish/` folder committed with a JWT key
- `publish/appsettings.json` contains a JWT signing key (the API itself reads from user secrets since auth Phase 0).
- Direction: ask Belal whether any server runs from this `publish/` output; remove `publish/` from git (`git rm -r --cached publish`) and add it to `BACKEND/.gitignore`; if that key was ever used anywhere, rotate it. Also ask about the loose root files `apply_phase1.py`, `apply_phase2.py`, `phase1-core.patch` before touching them.

### C16 (part 1) — Access token lifetime 600 min
- `JwtSettings.DurationInMinutes`. Direction: 15 min (refresh rotation already exists). Check where the running value comes from (user secrets / appsettings). The per-request stamp/permission check is M1 (decision D3), not F0.
