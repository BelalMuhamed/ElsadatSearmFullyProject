الخصومات العامة

التلات خصومات دول بيتملوا لوحدهم في أي فاتورة بيع للعميل اللي مالوش خصومات خاصة. العميل اللي ليه خصم خاص بياخد بتاعه هو. وأي قيمة تتعدّل وقت عمل الفاتورة.
