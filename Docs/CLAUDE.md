# Docs folder

The main instructions for Claude Code are in `CLAUDE.md` at the **repo root** (one level up). Follow that file; this folder only holds documents:

- `docs/refactor/` — backend refactor plan (`PLAN.md`) and step briefs (`F0.md`, …).
- `docs/ui/` — the new UI contract (README, text digest, `.dc.html` screens, tokens).
- `docs/requirements/`, `docs/inputs/` — customer stories PDF, older backend analysis.
- `docs/sadat-searm-ui-redesign.md` — design handoff (same content as `docs/ui/README.md`, older wording).
- `docs/chat-history.md` — the redesign conversation (text only).
- `design/` — previews (`preview/index.html`), screenshots (`screenshots/*.png`), original canvas sources (`source/`), `sr.css`.

The status/handoff file is `PROJECT_CONTEXT.md` at the repo root.
